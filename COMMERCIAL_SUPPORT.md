- candlestick and line-chart integration;

- zoom, pan, crosshair, hover, selection, and input behavior;
- Android, iOS, Web, macOS, Windows, and Linux compatibility;
- Flutter rendering or state issues that can be reproduced in a minimal project.

可处理 K 线/分时图集成、数据模型映射、缩放、拖动、十字线、悬停、选择回调、多端兼容，以及能在最小项目中复现的 Flutter 渲染或状态问题。

## Service options / 服务方式

### Root-cause diagnosis / 根因诊断 — CNY ¥99

For one reproducible issue: up to 45 minutes of log, configuration, and critical code-path review, followed by a written diagnosis and action checklist. No code patch is included.

针对 1 个可稳定复现的问题：材料齐全后进行最多 45 分钟排查，交付书面根因判断与处理清单；不包含修改代码。

### Narrow bug fix / 单点修复 — CNY ¥599

For one narrow, reproducible issue: root-cause analysis, the smallest safe patch, source or patch delivery, change notes, verification steps, and one acceptance correction for the same issue in the agreed environment.

针对 1 个单一、可复现问题：原因定位、最小安全修复、源码或补丁、变更说明、验证步骤，以及约定环境下同一问题的 1 次验收修正。

If a ¥99 diagnosis is upgraded to the ¥599 fix on the same day, the diagnosis fee is fully credited and only ¥500 remains.
