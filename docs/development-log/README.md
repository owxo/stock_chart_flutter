# 开发日志说明

本目录按日期记录项目每日开发进展。每次开发结束前都要更新当天日志，用于追踪已完成事项、验证结果、风险和待办专项。

## 文件命名

- 日期格式：`YYYY-MM-DD.md`
- 示例：`2026-06-20.md`

## 记录要求

- “已完成”记录实际完成的开发、修复、文档或验证工作。
- “变更文件”记录本次改动涉及的主要文件。
- “验证”记录运行过的命令和结果；没有运行时写明原因。
- “待办专项”记录下一步仍需推进的具体事项。
- “备注”记录上下文、风险、决策原因或外部依赖。

## 新建日志

当天日志不存在时，复制 `TEMPLATE.md` 的结构并替换日期。一个日期只维护一个日志文件，后续同一天工作继续追加到同一个文件。
